## Was ich gerade mache

- **GeMainsam / Mainsam** — nachhaltige Alltagsentscheidungen in Frankfurt sichtbar machen. 🥈 2. Platz beim FES Hackathon 2026, Frankfurt Impact Challenge. In 24 Stunden mit Team 01 gebaut.
- **PomodoroTimer** — native macOS-App, die ich selbst täglich benutze. Von SwiftUI über WidgetKit bis Siri Shortcuts komplett selbst gebaut.
- Nebenbei: Datenintegration, die auch dann noch etwas anzeigt, wenn die API im Demo ausfällt.
